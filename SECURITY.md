# Security Policy

## Reporting a Vulnerability

If you think that you found a security vulnerability in DSP-TOOLS,
report it privately by email to [security@dasch.swiss](mailto:security@dasch.swiss).
Do not open a public GitHub issue for a suspected vulnerability.

Include as much detail as you can:

- The affected version of DSP-TOOLS
- The command or the `xmllib` function that is affected
- The steps to reproduce the issue
- The potential impact

## Response Expectations

We acknowledge a report within a few business days.
We keep you informed while we investigate and fix the issue.

## Supported Versions

DSP-TOOLS is published on [PyPI](https://pypi.org/project/dsp-tools/).
Only the latest release on PyPI receives security fixes.
Before you report an issue, make sure that it occurs with the latest release.
