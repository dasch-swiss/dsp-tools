# dsp-vre-lib

`dsp-vre-lib` is a Python package for all interaction with a DaSCH Service Platform (DSP) server.
DaSCH tools, DaSCH services and researchers use it in their code.

The package is in an early stage and has no public interface yet.
The decisions about the interface are in the
[ADR for `dsp-vre-lib`](https://github.com/dasch-swiss/dsp-tools/blob/main/packages/dsp-tools/docs/dsp-tools-split/ADR-dsp-vre-lib.md).
